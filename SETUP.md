# Quick setup checklist

- [ ] Create a free Supabase project.
- [ ] Run `supabase/schema.sql` in the Supabase SQL Editor.
- [ ] Copy the Project URL and anon key into a local `.env` file.
- [ ] Run `npm install` and `npm run dev`.
- [ ] Submit a test RSVP.
- [ ] Confirm the test appears in `wedding_rsvps` in Supabase.
- [ ] Deploy to Vercel and add the same environment variables.
- [ ] Share the deployed website link with guests.

Never put the Supabase `service_role` key in this website.
